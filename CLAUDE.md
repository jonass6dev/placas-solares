# Instalación de placas solares en casa (guía paso a paso)
La idea con esta web es presentar al usuario, con una serie de imagenes y texto explicativo, el funcionamiento de unas placas solares instaladas en casa (proceso de instalación)

## Tecnologías y stack
Uso de HTML, CSS y JS normales. 

## Estilo
**Theme:** light
Simple, claro, conciso, bordes redondeados, el usuario debe de entender bien el contenido, para ello buscamos claridad en el diseño
